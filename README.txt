DKTE NSS WEBSITE — UPLOAD GUIDE

This package contains the website homepage (index.html), thank-you page, and this guide.
The Instagram section for @nss_dkte is included in index.html.

UPLOAD TO A NEW GITHUB REPOSITORY
1. Extract this ZIP file on your computer.
2. Open your new GitHub repository and choose Add file > Upload files.
3. Upload index.html and thank-you.html from the extracted folder (not the ZIP itself).
4. Commit the changes to the main branch.
5. In Settings > Pages, select Deploy from a branch, branch main, folder /(root), then Save.
6. Wait a few minutes for GitHub Pages to publish.

Keep both HTML files in the repository root. The website uses embedded media in index.html, so no separate assets folder is required for those embedded visuals.
